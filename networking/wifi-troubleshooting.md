# Wi-Fi Troubleshooting (Windows 10)

## Symptoms
- No internet access
- Slow connection
- Intermittent disconnects

## Troubleshooting

### Wi-Fi Icon (Laptop Only)
No visable Wi-Fi icon located in the notification area of the taskbar?

-> Check for Wi-Fi button to be enabled on laptop.

### Airplane Icon
Visable airplane icon located in the notification area of the taskbar?

-> Disable airplane mode from taskbar icon, or if available on hardware use keystroke/button to disable.

### Restart Systems
Power cycle modem/router and Windows device.

### Adapter Issues
1. Open Device Manager (right-click Windows Start logo or search "Device Manager" or from Control Panel).

2. Under "Network adpaters" right-click Wi-Fi adapter and Uninstall device **WITHOUT** deleting driver software.

3. Scan for hardware changes under Action tab.

4. Under "Network adpaters" right-click Wi-Fi adapter and Update driver to start installation wizard.

5. Select "Browse my computer for drivers".

6. Select "Let me pick from a list of available drivers on my computer".

7. Choose from a preallocated list of available drivers (select the one with the newest date).

### Restore Advanced Internet Settings
1. Search "Internet Options" from the Start menu.

2. Under the Advanced tab, select "Restore advanced settings" (computer restart maybe be required).

### Network Troubleshooter
1. Open the Start menu and select the Settings app (gear icon).

2. Select the Network & Internet icon.

3. Select the Network troubleshooter and run through the diagnostic wizard.

### Network Setting Reset
1. Open the Start menu and select the Settings app (gear icon).

2. Select the Network & Internet icon.

3. Select Network Reset and then Reset now.

## Resolution
Wi-Fi connection should be restored and operational.

*Note: Not all troubleshooting steps need to be executed for Wi-Fi to be reoperational.*
